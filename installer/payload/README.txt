LuminaCoder 1.0.0
=================

A local MCP-driven coding agent powered by DeepSeek V4 Flash.

Install
-------
Run LuminaCoder-Setup-1.0.0.exe. It will install LuminaCoder to
%LOCALAPPDATA%\Programs\LuminaCoder and add shortcuts to the Start Menu
and Desktop.

Uninstall
---------
Run the bundled uninstall.cmd in the install directory, or delete the
folder and shortcuts manually.

First run
---------
Open Settings (gear icon) -> Models, click "..." on DeepSeek V4 Flash and
enter your DeepSeek API key.
